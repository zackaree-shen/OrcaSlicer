Quick Start

1

Ensure Python 3.8+ is installed. Run python --version to check.

2

Double-click start.bat, or run in terminal:

python tools/cli_test_tool/app.py
3

Browser opens automatically at http://127.0.0.1:18964. The interface is in Chinese by default.

The tool auto-detects the CLI binary (snapmaker-orca-cli.exe) from the build output directory. If not found, a warning banner appears.

Configuration

In the Settings panel (click the header to collapse/expand):

FieldDescription
CLI PathPath to snapmaker-orca-cli.exe. Auto-detected from build/src/Release/. Use Browse to pick manually.
Data DirectoryPath to the resources/ folder. Contains printer profiles, fonts, etc.
Output DirectoryWhere G-code files and quality reports are saved. Defaults to slice_output.

Basic Workflow

1

Select input - Enter a path to a single .3mf file or a directory. Use File or Folder browse buttons.

2

Scan - Click "Scan 3MF Files" to discover all .3mf files. Uncheck any you want to skip.

3

Start Slicing - Click "Start Slicing". A live progress bar shows "N / Total (X%)" and the current file.

4

Review - Results appear as cards in real-time with status, duration, exit code, logs, and error analysis.

5

Quality Reports - Switch to the Quality Reports tab to see G-code quality scores. Click any row for a detailed report.

6

Export - Click "Export Report" to download a standalone HTML summary.

Slice Results Dashboard

The Slice Results tab shows:

Statistics

Total / Success / Failed / Timeout / Crashed counts, success rate, total time.

Filters

Filter cards by status: All, Success, Failed, Timeout, Crashed, Skipped.

Per-File Cards

Each 3MF gets a card with status badge, duration, exit code, G-code paths.

Error Analysis

Automatic failure reason detection with suggestions and keyword highlights.

Log Summary

Key log lines auto-extracted - warnings, errors, milestones. Collapsible.

Full Log

Complete CLI output, collapsible. Dark terminal theme.

Live Progress

Per-card progress bar during slicing, with percentage and stage label.

Quality Badges

Click quality score badges on each card to open detailed reports.

Status Types

SUCCESS CLI exited code 0 and produced G-code. FAILED CLI exited non-zero. TIMEOUT Exceeded the timeout. CRASHED CLI process crashed (segfault). SKIPPED File was excluded or already done.

Quality Reports

The tool integrates gcode-diff - a Rust-based G-code quality analysis engine. After each successful slice, it scores the output across 18 dimensions:

CategoryDimensions
CoolingFan PWM range, part cooling commands
ExtrusionRetraction, extrusion uniformity, volumetric flow
TemperatureNozzle temp range, temperature stability
GeometryLayer height, overhang, print volume fit, first layer
MotionTravel efficiency, speed consistency, corner speed
StructureWall and shell, support ratio, layer consistency
Thermal PhysicsMin layer time, weld bond strength (de Gennes/Wool model)
Multi-ExtruderTool changes, purge blocks, wipe tower workflow

How to Use

  • Switch to the Quality Reports tab after slicing completes.
  • A summary table shows each G-code file's score, rating (Excellent/Good/Fair/Poor), and CRITICAL flag.
  • Click any row to open a full-screen detailed report with per-dimension breakdown, physics status, and recommendations.
  • Use the language toggle button (top-right) to switch between Chinese and English. Defaults to Chinese.
  • Use the back button (top-left) or close button to dismiss.
  • Quality badges also appear on result cards in the Slice Results tab.

ScoreRatingMeaning

Export and Reports

  • Export Report - Click after slicing to download a standalone HTML summary with all results and logs.
  • Output Structure:
    output_dir/ _reports/ report_20260729_143000.json # session report 3mf_file_name/ plate_1.gcode # sliced G-code quality_plate_1.html # quality report (per plate)
  • Clear Session - Click "Clear" to reset all results and start fresh.

Troubleshooting

CLI not found

An orange warning banner appears if snapmaker-orca-cli.exe cannot be found. Use Browse in Settings to locate it. Expected path: build/src/Release/.

All files show CRASHED

Usually a CLI runtime issue. Check: data directory path is correct, all required DLLs are next to the exe, binary was built in Release mode.

Relative extruder error

Enable "Use Relative E=0" in Advanced Options.

Browse button not working

Type paths directly into the text fields. Use forward slashes or backslashes.

Port already in use

Kill the process on port 18964, or modify the PORT variable at the top of app.py.
