快速上手

1

确保已安装 Python 3.8+。运行 python --version 确认。

2

双击 start.bat，或在终端运行：

python tools/cli_test_tool/app.py
3

浏览器自动打开 http://127.0.0.1:18964。界面默认为中文。

工具会自动检测 CLI 二进制文件（snapmaker-orca-cli.exe），默认从构建输出目录查找。如果未找到，会显示橙色警告条。

基本配置

在"设置"面板中（点击标题栏可折叠/展开）：

字段说明
CLI 路径snapmaker-orca-cli.exe 的路径。默认从 build/src/Release/ 自动检测。可点击"浏览"手动选择。
数据目录resources/ 目录路径。包含打印机配置文件、字体等。
输出目录G-code 文件和质量报告的保存位置。默认为 slice_output。

使用流程

1

选择输入 — 输入单个 .3mf 文件路径或包含多个 .3mf 的目录。可使用"文件"或"目录"浏览按钮。

2

扫描 — 点击"扫描 3MF 文件"发现所有 .3mf 文件。取消勾选不需要切片的文件。

3

开始切片 — 点击"开始切片"。实时进度条显示"N / 总数 (X%)"及当前正在切片的文件。

4

查看结果 — 切片结果以卡片形式实时显示，包含状态、耗时、退出码、日志和错误分析。

5

质量报告 — 切换到"质量报告"标签页查看 G-code 质量评分。点击任意行打开详细报告。

6

导出 — 点击"导出报告"下载独立的 HTML 汇总文件。

高级选项

在设置面板中点击"高级选项"展开：

选项默认值说明
切片模式所有盘 (0)选择切片的盘：0 = 全部，1-3 = 指定盘。
每盘最大时间(秒)0--mstpp — 每个盘的最大切片时间。0 = 无限制。
最大三角形数0--mtcpp — 三角面片上限。0 = 无限制。适合压力测试大模型。
调试级别30（仅错误）到 5（完整跟踪）。越高输出越详细。
超时(秒)600每个文件的墙钟时间限制。超时文件标记为 超时。
额外参数（空）任意额外的 CLI 参数，如 --no-check --orient 1。
跳过版本检查勾选添加 --allow-newer-file，跳过版本不匹配错误。
Use Relative E=0不勾选添加 --use-relative-e-distances=0。修复部分 3MF 的"relative extruder error"。
如果在日志中看到 relative extruder error，请在高级选项中勾选"Use Relative E=0"。

切片结果面板

切片结果标签页包含以下功能：

统计数据

总计 / 成功 / 失败 / 超时 / 崩溃 数量，成功率，总耗时。

状态筛选

按状态筛选卡片：全部、成功、失败、超时、崩溃、跳过。

每文件卡片

每个 3MF 一张卡片，显示状态徽章、耗时、退出码、G-code 输出路径。

错误分析

自动检测失败原因，给出修复建议（黄色框）和关键词高亮。

日志摘要

自动提取关键日志行 — 警告、错误、重要里程碑。可折叠。

完整日志

完整的 CLI 输出，可折叠。深色终端主题，便于阅读。

实时进度

切片时在卡片内显示进度条，标注百分比和当前阶段。

质量徽章

点击卡片上的质量分数徽章，直接打开详细质量报告。

状态类型

成功 CLI 退出码为 0 且生成了 G-code。 失败 CLI 退出码非零。 超时 超过了配置的超时时间。 崩溃 CLI 进程崩溃（段错误等异常终止）。 跳过 文件被排除或已完成。

质量报告

工具集成了 gcode-diff — 一个基于 Rust 的 G-code 质量分析引擎。每次切片成功后，自动对输出进行 18 个维度的评分：

类别维度
冷却风扇 PWM 范围、部件冷却指令
挤出回抽、挤出均匀性、体积流量
温度喷嘴温度范围、温度稳定性
几何层高、悬垂、打印体积适配、首层
运动空驶效率、速度一致性、拐角速度
结构墙壁与外壳、支撑比例、层一致性
热物理最小层时间、焊接结合强度（de Gennes/Wool 模型）
多挤出头换色次数、清仓块、擦塔工作流

如何使用

  • 切片完成后，切换到质量报告标签页。
  • 汇总表格显示每个 G-code 文件的评分、评级（优秀/良好/一般/较差）和严重问题标记。
  • 点击任意行打开全屏详细报告，包含：各维度分数与严重程度、判定说明、推荐参数调整、物理验证状态和材料各向异性信息。
  • 报告右上角有语言切换按钮（中文/English），默认中文。
  • 左上角有返回按钮，右上角有关闭按钮。
  • 切片结果面板的每个卡片上也会显示质量徽章。

评分解读

分数评级含义
80-100优秀 / 良好打印质量预期较高。
60-79一般部分问题可能影响表面质量或尺寸精度。
0-59较差存在严重质量问题 — 请查看推荐建议。

导出与报告

  • 导出报告 — 切片完成后点击"导出报告"，下载包含所有结果和日志的独立 HTML 文件，可分享。
  • 输出目录结构：
    output_dir/ _reports/ report_20260729_143000.json # 会话报告（机器可读） 3mf_file_name/ plate_1.gcode # 切片生成的 G-code quality_plate_1.html # 质量报告（按盘生成）
  • 清空会话 — 点击"清空"重置所有结果，重新开始。防止上次切片的残留数据影响新任务。

常见问题

找不到 CLI

如果找不到 snapmaker-orca-cli.exe，会显示橙色警告条。在设置中点击"浏览"手动定位。预期路径：build/src/Release/。

所有文件都崩溃

通常是 CLI 运行时问题。检查：数据目录路径正确、所有依赖 DLL 与 exe 在同一目录、CLI 为 Release 模式编译。

Relative extruder error

在高级选项中勾选"Use Relative E=0"。

浏览按钮无响应

可以直接在文本框中手动输入路径，使用正斜杠（/）或反斜杠（\）均可。

端口被占用

结束占用 18964 端口的进程，或修改 app.py 顶部的 PORT 变量。

技术栈：Python 3.8+ 标准库（零依赖）、原生 HTML/CSS/JS 前端、gcode-diff Rust 质量引擎、可选 Electron 打包。
